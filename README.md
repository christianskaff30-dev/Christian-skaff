# AURELLE — The Everyday Edit

A responsive React + Vite starter for the AURELLE personal productivity workspace.

## Run
Install Node.js, then in this folder run:
```bash
npm install
npm run dev
```
Open the local URL shown by Vite.

## Build
```bash
npm run build
```

## Publish to GitHub
Create an empty GitHub repository, then run:
```bash
git init
git add .
git commit -m "Initial AURELLE dashboard"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/aurelle-everyday-edit.git
git push -u origin main
```
Replace YOUR-USERNAME with your GitHub username.

## Included
- AURELLE beige, cream and champagne visual style
- Overview with ten workspace areas
- Add, complete, search and delete tasks
- Browser localStorage persistence

## Important limitations
This is a front-end prototype. It does not yet have accounts, cloud sync, payments, or a live ClickUp connection. Tasks are saved only in the browser/device where entered. Add a secure backend before launching it commercially.
